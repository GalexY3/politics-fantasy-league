**A — Pregunta y población:** determinar si dos rankings de competiciones diferentes permiten comparación pareada de *modelos* sobre agregados, unidad «Team + Model Organization + Model», nunca persona ni unidad de asignación. **B — H1:** existe subconjunto de al menos 10 modelos idénticos con Overall, N y rank comparables descriptivamente, N≥20 en ambos; H0, solapamiento insuficiente o sesgo de cobertura impide comparación interpretable. Rival: incluso con las mismas etiquetas/N los universos de preguntas, muestras y participantes del leaderboard pueden variar; rango no es estimando causal. **C — Diseño:** fijados originales y hashes, matching exacto, excluir duplicados, N mínimo, errores de CSV y recuentos, sin IDs en output. **D — Freeze:** [A–J y SHA antes de outcomes](C31_PREREG_AJ_SHA.json), commit `7d0d6f921ce093e5f9f92d8cc2ba8b35d463cec8`; código Git blob `9feecfa486fd8c5ecebe50608146eacc6e3974fa`, pruebas Git blob `ec4d4c6bea273d6dc8522974dd43a2ec6ccd9d1f`.

**E — Ejecución real:** el código Git original se interpretó con **V8 aislado**, quitando la sintaxis ESM `export` y ejecutando el cuerpo de los **11 tests originales** mediante un adaptador local de aserciones; **11/11 PASS**, no afirmar `node --test` nativo. Se cotejaron los cuatro Git blobs de fuente, instrumento y dos tablas, antes de analizar resultados; todas las filas procesadas eran agregados por modelo. El resultado preregistrado: **130 filas baseline, 464 torneo, 11 emparejamientos elegibles**, media de diferencia de `Overall` declarada **+0,33636 unidades de la columna**, mediana **0**, media de cambio de puesto **+296**, diferencia media de N **0** y 11/11 pares con N exactamente igual. **No interpretar rango de una tabla con 130 participantes contra otra de 464 como mejora o deterioro de predicción**.

**F — Control adversarial:** se examinó **post hoc**, no confirmatorio, la distribución de diferencias `Overall` sin revelar modelo: 6 pares exactamente iguales y cinco diferencias positivas [0,6, 0,6, 0,6, 0,9, 1,0]. Cambio de puesto oscila de +6 a +343 por cambio de universo. Este resultado alerta sobre una *media* dominada por pocos cambios y sobre interpretación causal improcedente de rankings.
