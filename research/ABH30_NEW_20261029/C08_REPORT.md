## Contrato A–J

**A. Pregunta/estimando.** ¿Puede restaurarse el historial original de dos rutas públicas de fuentes para responder a fechas intermedias, y qué cambia en el conjunto de oportunidades binarias elegibles cuando se introducen las versiones originales? Unidad = pregunta pública de evento × versión publicada de fuente Git; no persona, participación, bienestar, tratamiento ni causalidad.

**B. H1/H0/rivales.** H1: las versiones intermedias contienen información de fuente original que un comparador de tres versiones omite, potencialmente con altas, bajas o inversiones de resultados. H0: no hay nuevas oportunidades o cambios respecto a las tres versiones previas; conservar la nulidad si ocurre. Rival fuerte: el origen científico ForecastBench ya incorpora datasets dinámicos, y el incremento puede ser maduración ordinaria de resoluciones, no un mecanismo novedoso. No existe un comparador humano de habilidad predictiva en esta prueba.

**C. Fuente/diseño.** Repositorio público original `forecastingresearch/forecastbench-datasets`, documentación pública de ForecastBench ICLR 2025 y licencia CC BY-SA 4.0 para estos datos publicados. Se examinaron `commits?path=datasets/resolution_sets/2026-09-27_resolution_set.json&per_page=100` y su homólogo 11/10; después se verificaron las carpetas `question_sets` y `resolution_sets` en todos los commits originales. **Antes del preregistro** se inspeccionaron commit, tiempo y Git SHA de cada versión, **pero no el contenido de los trece archivos intermedios aún no vistos**. Dos preguntas originales fijadas por sus SHA anteriores. El corte máximo documentado es **2026-10-29T16:00:00Z**; el selector rechaza fechas posteriores o cohortes desconocidas. No se usa la versión Oct29 retroactivamente para fechas anteriores.

**E. Ejecución real y contabilización de pruebas.** Se evaluó en **V8 sobre el código original exacto congelado** la suite de **27/27 controles adversariales PASS**, con assertions de selección por versión, inicio de fuente, cortes futuros, comparación entre archivos, duplicados, supresión e inversión de Y. **Esto no es un test nativo Node; no se ha ejecutado esa suite como proceso Node.** Después se recuperaron por el conector GitHub los cuerpos de las 19 versiones de resoluciones y los dos archivos de preguntas, se calculó el SHA Git completo de los bytes originales de cada una, validando antes el vector independiente `git hash-object abc`. Se aplicó el verificador C07 congelado a las 16 + 3 versiones en **lotes solapados de hasta seis archivos**, para comparar directamente en memoria las claves y valores de Y entre cada pareja adyacente. Los solapamientos aseguran que también se verifican los límites entre lotes. El selector C08 fija qué fuente estaba publicada en cada corte. **No** se ejecutó un CLI nativo nuevo con los 21 originales descargados en el contenedor local (DNS bloqueado). Un análisis positivo de fuente original en V8 no debe describirse como ejecución positiva nativa de archivos locales.

**F. Auditoría adversarial/negativos.** Fuente original Git SHA, corte UTC canónico, `source+id` y no mezcla de unidades, rechazo de fuentes económicas no probabilísticas, preguntas o fechas inválidas y años no examinados. El resultado de cero inversiones se refiere exclusivamente a las **preguntas binarias de mercado que cumplían el filtro**. Además, se documenta expresamente la **disminución de filas brutas de resolución** como contraejemplo a un modelo simple append-only. El hecho de que el resultado observado fuera cero inversiones no reduce la obligación de registrar modificaciones en una fuente futura. Limita la inferencia temporal a la ruta del repositorio original Git; el `resolution_date` de un evento no es el sello `first_public_at` de su plataforma de origen.

Comparadores y réplica.** C07: tres cortes y dos cohortes del mismo proveedor; C08 añade la secuencia íntegra de publicación **en ese proveedor**, no otra población ni una fuente causal independiente. Un comparador competente de predicciones humanas y sus exposiciones está fuera de esta prueba. No se afirma descubrimiento científico 1/3–3/3 ni atribución causal.
