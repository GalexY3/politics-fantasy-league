**A:** identificar si se puede obtener y usar legalmente una nueva clase de observaciones humanas para análisis descriptivo, no una prueba causal de PFL. **B:** H1 JSON individual original bajo licencia CC BY-SA 4.0 accesible y seguro para análisis sin identificadores; H0 acceso parcial o datos con identificadores y texto libre requieren más control. **C:** fuente congelada ForecastBench `027ba0b3017a60e0e64602d724284ac6b2d91134`, README SHA `1edea28cb04516a41d3878860bfca905ee1fa094`, LICENSE SHA `4a771ccadef06d2509ca54ea80e8427a14e5c667`; objeto super individual SHA `583085efe4c752d4b9f6ab2c98ec8642fbc01bca`, pública individual es puntero LFS `5653e59c09daa14b0a203a23d2bd0193e836b43b`. **D:** [contrato A–J](C18_PREREG_AJ_SHA.json) commit `9331e120b84844f94babcbfc25797e51cb24e4ad` se congeló antes del intento de leer registros. **E:** se ejecutó una sola lectura del JSON individual super de ~4,6 MB mediante GitHub y parseo in-memory solo a metadata. Fracasó con `SyntaxError: Unexpected end of JSON input`. **No se produjo JSON válido, no se calcularon registros ni pronósticos y no se reintentó**. Después, revisión **post hoc** de la vista pública de Hugging Face identificó campos `user_id` y `reasoning` de texto libre en previsiones individuales; no se copiaron valores ni se almacenaron identificadores. La existencia de una licencia de copyright CC BY-SA **no es base suficiente por sí sola** para tratar identificadores personales o pseudónimos de ciudadanos en una investigación nueva. [Recibo](C18_RUN_RECEIPT.json).
