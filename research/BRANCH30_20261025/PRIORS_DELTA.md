No son probabilidades calibradas ni afirmaciones empíricas; su alcance se restringe a la instrumentación y riesgos metodológicos. Los hallazgos ya conocidos por literatura no se reclaman originales.

1. **PFL-P01 · No-voto/ausencia no equivalentes.** Procedencia: definición de contrato nominal y `test_br30_07`; evidencia favorable: test negativo que representa fila ausente y devuelve `unknown`; contra: el formato de cada fuente puede disponer de ausencias explicitadas u omisiones, SIN CERTIFICAR; falsador: JSON real contradice categorías y exige nuevo diccionario.
2. **PFL-P02 · Tiempo de disponibilidad y de registro no intercambiables.** Procedencia: `rollcall_as_of` y tests 03–05; favor: invariantes deterministas; contra: históricas `first_public_at` / revisiones upstream todavía no verificadas; falsador: fuente no provee tiempo de publicación documentable.
3. **PFL-P03 · Afiliación retroactiva cambia la estimación.** Procedencia: `group_at_vote` y test 06; favor: fixture de cambio A->B; contra: todavía no hay cambios institucionales reales medidos; falsador: disponibilidad universal de historial de grupo o datos congelados por fuente.
4. **PFL-P04 · La composición de agenda puede invertir resultados descriptivos.** Procedencia: test de Simpson 16 con tasas construidas; favor: cálculo aritmético reproducible; contra: **no** constituye hallazgo en instituciones ni demostración causal; falsador empírico: ausencia de inversión bajo cualquier estratificación preregistrada con corpus real.
5. **PFL-P05 · Covoto bruto engañoso cuando las elecciones marginales se concentran.** Procedencia: test 18 (votos siempre YES: acuerdo1, exceso0); favor matemático bajo baseline de independencia marginal; contra: baseline no corrige correlación temporal ni disciplina de partido; falsador empírico: ausencia de diferencia inferencial tras modelos relacionales fuertes.
6. **PFL-P06 · Unidades independientes para uncertainty no deben asumirse votos individuales.** Procedencia: bootstrap cluster por sesión 24; favor: no re-muestrea filas; contra: dependencia entre sesiones puede continuar; falsador: otras dependencias exigen unidad de remuestreo más amplia.
7. **PFL-P07 · VSDS representa utilidad y novedad por separado.** Procedencia: decisión del usuario + test 28; favor: API etiqueta escala; contra: grading ordinal no calibrado y susceptible a inflación si no se exigen certificados; falsador: auditoría externa descarta utilidad alegada.
